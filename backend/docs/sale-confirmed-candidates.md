# MVP 추천 후보와 순위

MVP에서는 활성 카탈로그에 등록된 실제 메뉴 전체를 판매 가능으로 간주합니다. 기본 데이터는 카페 320곳의 메뉴 5,011건입니다. 별도 판매 확인이나 메뉴 ID 등록 없이 추천을 실행할 수 있습니다. 시즌 종료로 기록된 40건도 후보에 포함됩니다.

이 정책은 추천 조회에 적용됩니다. 원본의 `availability`, `saleConfirmation`, 수집 날짜를 그대로 보존합니다. 화면은 해당 메뉴의 실시간 재고나 매장 판매 확인을 보장하지 않습니다.

## 카드 선택

1. 활성 데이터 버전에서 `isDemo=false`인 메뉴를 읽고 요청의 `excludedMenuIds`에 포함된 메뉴를 제외합니다.
2. 사용자가 선호를 밝힌 종류·가격대·단맛·커피 기반·제공 온도·시그니처가 근거 있는 메뉴값과 일치할 때 속성당 1점을 줍니다. 커피 기반은 음료 선호일 때만 적용합니다. 온도를 둘 다 제공하는 메뉴도 온도 점수는 최대 1점입니다.
3. 높은 점수부터 정렬하고 동점은 카탈로그 등록 순서로 결정합니다. 무선호·미확인 값은 가점이 없습니다. 모두 건너뛰면 등록 순서를 따릅니다.
4. 같은 PostgreSQL 스냅샷에서 첫 메뉴와 카페를 조회합니다. 좌표가 없거나 지도 투영 범위를 벗어나면 길찾기 URL은 null입니다.

후보가 소진되면 `{"menu":null}`을 반환합니다. 활성 카탈로그가 없거나 DB 조회가 실패하면 서비스 오류를 반환합니다. HTTP 계약은 PR #26의 `backend/docs/preferences-openapi.yaml`에서 확인할 수 있습니다.
